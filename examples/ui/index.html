同一个服务，四个界面方向

四个都是活的，连的是你正在跑的服务（真实数据：示例市、示例市两个任务）。 内容一样，差的是布局、视觉、引导方式。挑一个，或者告诉我"要 A 的布局配 C 的配色"这种混搭。

单独打开 ↗ A · 聚焦单栏

进来就是一件事：填目录 → 点开始 → 看结果。历史收在底部。 极简留白、大字号、无边框卡片。最不像后台管理系统

单独打开 ↗ B · 后台双栏

左边一列是任务历史（常驻），右边是工作区。满屏宽，信息密度高。 企业后台观感，适合一次管好几个任务

单独打开 ↗ C · 门户宽版

你现在这张页面的加宽优化版：结构、配色照旧，把间距、字号、输入框都放大， 首屏加引导。改动最小、最容易接受

单独打开 ↗ D · 向导分步

四步走：选数据 → 确认 → 分析中 → 取结果。一次只给一步，大按钮大字号。 给完全不懂的人用，代价是老手嫌慢

提醒：四个页面每 5 秒都会去刷新任务列表，是真实请求。 我只做了读操作——没有提交任何新任务（提交会真的触发示例分析脚本）。
